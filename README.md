# asmel-site
Official website of ASmel / AS Hub

## LAB — Заказать разработку

Добавлен адаптивный блок заявок на разработку сайта, Android/ПК-программы и автоматизации. В текущей версии формируется **локальный черновик**, доступный для копирования или скачивания TXT.

**Важно:** автоматическая отправка и реальная доставка заказов не подключены. До подтверждения рабочего получателя, HTTPS API и публичной политики конфиденциальности \`data-endpoint\` остаётся пустым; нельзя считать форму готовой к коммерческому приёму заказов.

Подробнее: [docs/ORDERS_LAB.md](docs/ORDERS_LAB.md).
